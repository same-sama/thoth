# Thoth 网站（GitHub Pages）

隐私政策、支持页、自部署接入说明、Mods 投稿条款。App 里的链接（`Thoth/Core/AIDataConsent.swift` 的 `ThothLinks`）指向：

- https://same-sama.github.io/thoth/
- https://same-sama.github.io/thoth/privacy.html
- https://same-sama.github.io/thoth/support.html
- https://same-sama.github.io/thoth/self-hosting.html
- https://same-sama.github.io/thoth/mods-terms.html

## 发布

1. 在 GitHub 上新建一个**公开**仓库，名字叫 `thoth`（地址就是上面的 `/thoth/`；换名字的话，App 里的 `ThothLinks` 也要一起改）。
2. 把这个文件夹里的文件放到仓库根目录，提交、推送。
3. 仓库 Settings › Pages › Build and deployment：Source 选 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 一两分钟后打开 https://same-sama.github.io/thoth/ 确认能访问。
5. App Store Connect 里：隐私政策网址填 `.../privacy.html`，支持网址填 `.../support.html`。
