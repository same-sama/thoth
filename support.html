常见问题

Thoth 要钱吗？要注册吗？

App 免费，不用注册。朋友的回复由你自己接入的模型服务生成，费用按那家服务的价格，由你直接付给它。

去哪里拿 API Key？

在你想用的模型服务官网注册并创建 API Key（比如 OpenAI、Anthropic、DeepSeek、阿里云百炼），然后在「设置 › 模型与服务 › 模型服务」里添加。Key 只存在你手机的钥匙串里。

我的聊天会被谁看到？

聊天和记忆存在你的手机上。回复时，相关内容会直接发给你选的模型服务，不经过我们。详见隐私政策。

能用自己部署的模型、语音或生图服务吗？

能，只要兼容 OpenAI 的接口格式。见自部署服务接入说明。

怎么删除数据？

删除一位朋友会删掉 TA 的全部文件；删除 App 会删掉全部本地数据。Mods 的作者资料在「Mods › 我的 Mods › 作者资料」里删除；已发布的作品和投稿写信给我们删除。

看到不当内容怎么办？

在作品页右上角「···」里举报，或者写信给我们。被举报的内容会由人工审核，违规的会下架，发布者可能被禁止投稿。

よくある質問

料金や登録は必要ですか？

アプリは無料で、登録も不要です。友だちの返信は、あなたが接続したモデルサービスが生成します。料金はそのサービスの価格で、あなたが直接支払います。

API Key はどこで手に入りますか？

使いたいモデルサービス（OpenAI、Anthropic、DeepSeek、Alibaba Cloud Model Studio など）の公式サイトで登録して API Key を作成し、「設定 › モデルとサービス › モデルサービス」で追加してください。キーは端末のキーチェーンにだけ保存されます。

会話は誰に見られますか？

会話と記憶は端末に保存されます。返信の際、関係する内容はあなたが選んだモデルサービスへ直接送られ、私たちを経由しません。詳しくはプライバシーポリシーをご覧ください。

自分で立てたモデル・音声・画像生成サービスは使えますか？

OpenAI 互換の形式なら使えます。自分で立てたサービスの接続方法をご覧ください。

データを削除するには？

友だちを削除するとその友だちのファイルはすべて削除され、アプリを削除するとすべてのローカルデータが削除されます。Mods の作者プロフィールは「Mods › マイ Mods › 作者プロフィール」で削除できます。公開中の作品や投稿の削除はメールでご依頼ください。

不適切な内容を見つけたら？

作品ページ右上の「···」から報告するか、メールでお知らせください。報告された内容は人の手で確認し、違反したものは非公開にします。投稿者は投稿できなくなることがあります。

FAQ

Does Thoth cost anything? Do I need an account?

The app is free and needs no account. Your friends' replies come from a model service you connect; you pay that service directly at its own prices.

Where do I get an API key?

Sign up on the website of the model service you want (OpenAI, Anthropic, DeepSeek, Alibaba Cloud Model Studio and others), create an API key, then add it in Settings › Models & Services › Model Services. The key is stored only in your phone's Keychain.

Who can see my chats?

Chats and memories are stored on your phone. When a friend replies, the relevant content goes directly to the model service you chose, never through us. See the privacy policy.

Can I use a model, voice or image service I host myself?

Yes, if it's compatible with the OpenAI API format. See connecting a self-hosted service.

How do I delete my data?

Deleting a friend deletes all of their files; deleting the app deletes all local data. Delete your Mods author profile in Mods › My Mods › Author Profile; to remove published Mods or submissions, email us.

What if I see inappropriate content?

Report it from the ··· menu on the Mod's page, or email us. Reports are reviewed by a person; violating content is taken down and the submitter may be barred from submitting.
